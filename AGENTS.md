
# AGENTS.md

## 1. Project Overview

Project Name: Japan Travel Explorer

Japan Travel Explorer is an interactive Japan travel
guide website.

Users can explore Japan through an interactive map
and discover travel information about different regions.

The website focuses on tourism, attractions, food,
transportation, and travel itineraries.

## 2. Project Goals

- Create an interactive Japan travel website.
- Use Japan's map as the main navigation interface.
- Allow users to explore Japan's eight regions.
- Provide useful travel information for each region.
- Create a responsive and visually appealing website.

## 3. Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- GitHub Pages

Avoid unnecessary frameworks and dependencies.

## 4. Project Structure

- index.html: Main homepage.
- AGENTS.md: AI development guidelines.
- README.md: Project documentation.
- css/: Website stylesheets.
- js/: JavaScript functionality.
- pages/: Regional travel guide pages.
- images/map/: Japan map assets.
- images/destinations/: Destination photographs.
- images/icons/: Website icons.

## 5. Website Design

### Visual Style
- Theme: Luxury Japan Travel.
- Main colors: Dark navy, charcoal, and gold.
- Text colors: White and warm gray.
- Design: Modern, elegant, and minimal.
- Use subtle animations and smooth transitions.

### Homepage
- Display the website title and navigation.
- Use an interactive Japan map as the main visual.
- Support hover effects for the eight regions.
- Display region names when users hover over the map.
- Navigate to the corresponding page when clicked.

## 6. Japan's Eight Regions

1. Hokkaido
2. Tohoku
3. Kanto
4. Chubu
5. Kansai
6. Chugoku
7. Shikoku
8. Kyushu

## 7. Destination Page Structure

Each destination page should follow this order:

1. Destination Cover
2. Regional Introduction
3. Recommended Attractions
4. Local Food
5. Transportation Guide
6. Recommended Itineraries

Keep the layout and visual style consistent across pages.

## 8. Content Guidelines

- Write content in Traditional Chinese.
- Include English names for important locations.
- Use concise and useful travel information.
- Do not invent opening hours, ticket prices, or transportation schedules.
- Use relevant and properly sourced information.
- Use high-quality destination images.

## 9. File Naming Rules

- Use lowercase English filenames.
- Use hyphens to separate words when necessary.
- Keep HTML, CSS, and JavaScript in their designated folders.
- Store destination images in the corresponding folders.
- Avoid unnecessary duplicate files.

## 10. Development Rules

- Keep HTML, CSS, and JavaScript separate.
- Use semantic HTML elements.
- Write readable and maintainable code.
- Make the website responsive.
- Ensure all navigation links work correctly.
- Test new features before considering them complete.
- Preserve existing working functionality.

## 11. AI Development Instructions

Before modifying the project:

1. Read this AGENTS.md file.
2. Understand the existing project structure.
3. Follow all design and development guidelines.
4. Reuse existing components and styles when possible.
5. Avoid modifying unrelated files.
6. Explain important changes when necessary.
7. Check that the website still works after modifications.
